# 【以赛促练  技能比武】 我院开展手卫生及职业防护技能竞赛

> 更新时间：2026-09-16 (UTC+8)

当前新冠疫情防控形势复杂，为进一步做好公共卫生医疗保障，增强医护人员手卫生与职业防护意识，提高职业防护技能，降低职业暴露风险，4月22日下午，我院感染管理科、医务科、护理部、工会联合举办手卫生及职业防护技能竞赛。党委书记孙春霞、院长刘先洋等院领导现场观摩。经过前期科室内选拔与推荐，共有54名选手参加了竞赛。

本次竞赛由医院相关职能科室主任担任评委，评委们依据《七步洗手法评分标准》、《穿脱防护用品评分标准》对各选手的操作流程进行现场评分，现场气氛紧张而激烈。经过激烈角逐，最终评选出医生组戈婷婷、护士组秦怡分别获得竞赛一等奖，急诊科获得组织奖。

赛后，各评委还针对比赛中的亮点及不足进行了点评。评委们强调，院感工作是红线，大家一定要树立底线思维，明确职责，严格执行院感制度，在思想上要高度重视，紧绷疫情院感防控这根弦，提高政治站位、保持“警觉”意识。

职业防护技能竞赛组织有序、流程清晰、评分严谨科学，参赛选手知识掌握扎实、操作规范流畅，充分展示了我院医护人员积极进取的精神风貌。

以赛促练，进一步提高医务人员的院感防控意识，同时把手卫生工作落到实处，使院感防控工作做得更细、更扎实，推动医院感染管理水平再上新台阶。
