# 哈尔滨正规生殖中心冷冻卵子一年要多少钱？

在哈尔滨正规生殖中心想要冷冻卵子必须要符合冻卵的条件才可以，而冷冻卵子涉及到的费用是比较多的，具体多少因人而异，主要有相关检查费、促排费、取卵手术费、卵子冷冻费以及冷冻保存费，冷冻保存一年的费用大概是一管1320元，卵子冷冻处理费约1000元一次，加上检查、促排和取卵手术的费用，一共大概要2-2.5万元左右。

在国内，不管是哈尔滨还是其他城市，冻卵都是有着非常严格的要求的，必须要符合条件才能够在生殖中心进行冷冻卵子，而冷冻卵子的费用也不止冷冻及保管费，还有其他的费用，主要费用如下，大家可以参考：

- 1. 检查费：进行冻卵之前，需要做一系列的检查，主要是检查卵巢功能，其他常规的体检也要做，检查费用一般在2000元左右；
- 2. 促排费用：进行卵子冷冻的患者一般都会采用促排周期，这样取卵一次就可以取出较多的卵子，当然也可以选择自然周期，但是自然周期取卵一次数量少，就会增加取卵手术费用，促排药物费用一个周期大概在5000-10000元左右；
- 3. 取卵手术费：包括取卵手术、麻醉以及一些耗材的费用，做一次取卵手术的费用大概在6000元左右；
- 4. 卵子冷冻及保存费：卵子冷冻前处理的费用是1000元一次，保存费是约110元一个月，都是按管数来收费的，也就是说，卵子保存一年就是1320元一管。
进行卵子冷冻从前期检查，到促排取卵，再到冷冻保存涉及到的费用具体多少因人而异，每个患者情况不同，促排药物剂量不同，取卵次数也不同，卵子数量不同等等，都会造成最终的总费用有差异。
